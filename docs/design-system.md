# Design system

這份文件說明 loadsketch 介面的外觀和動態規則。改 UI 之前先讀。樣式都在 `src/app/index.css`；這裡寫的是「什麼時候用哪一個」。

## 1. 原則

1. **資料最優先。** 數字、進度條、圖表、請求的點是模擬結果。任何裝飾都不能讓它們變難讀，也不能讓人誤讀它們的變化。
2. **玻璃只給浮在別的內容上面的東西。** 後面沒有東西的面，玻璃看不出來，只會降低對比。
3. **彈性只給「出現、消失、被按下、被拿起」的瞬間。** 版面大小的變化不回彈。資料的變化不加動畫。
4. **顏色有意義。** 類別色表示元件種類。綠、橘、紅表示狀態。藍表示選取和主要動作。裝飾不能搶這些顏色。
5. **深色和淺色都要看。** 每個改動都要在兩個主題截圖檢查。
6. **尊重「減少動態效果」。** `prefers-reduced-motion: reduce` 時，所有動畫和彈性都關閉。

## 2. Token

Token 定義在 `src/app/index.css` 的 `:root` 和 `:root.dark`。顏色值跟隨 kumo design system（對照表在該檔開頭的註解）。不要在元件裡寫死顏色。

| Token | 用途 |
|---|---|
| `--bg` | 畫布和頁面底色 |
| `--chrome` | 固定面板（頂端列、左右面板、執行列）的底色 |
| `--panel`、`--panel-2` | 卡片底色、hover 底色 |
| `--line`、`--line-strong` | 分隔線、邊框 |
| `--ink`、`--ink-2`、`--ink-3` | 文字：主要、次要、輔助 |
| `--accent` | 選取、主要按鈕、focus |
| `--ok`、`--warn`、`--bad` | 狀態。只用在狀態 |
| `--cat-traffic` … `--cat-messaging` | 元件類別色。只用在元件的 icon、卡片和連接點 |
| `--edge` | 連線和箭頭 |
| `--glass-bg` | 玻璃的底色（半透明的 `--panel`） |
| `--glass-blur` | 玻璃的模糊（`backdrop-filter` 的值） |
| `--dim` | 對話框後面的遮罩顏色 |
| `--spring` | 會稍微超過終點再回來的曲線。**只能用在 `transform`** |
| `--dur` | 顏色、邊框這類小變化的時間（100 ms） |

## 3. 玻璃

### 可以用玻璃的地方

| 東西 | class | 說明 |
|---|---|---|
| 畫布上的元件卡片 | `.sd-node` | 見第 5 節 |
| 連線上的標籤 | `.sd-edge-label` | |
| 浮在畫布上的卡片（題目、值班） | `.card.sd-float` | 從右上角彈出。標題和動作按鈕在同一行；內容在下面。上下左右的內距一致 |
| 浮在畫布上的其他卡片和按鈕（設計檢查；快取接資料庫時，畫布下方的 read-through 提示） | `.card.sd-over`、`.btn.sd-over` | 從左上角彈出 |
| 畫布的縮放按鈕 | `.react-flow__controls` | |
| 下拉選單和動作選單 | `.sd-menu` | |
| 圖表的 hover 提示框 | `.sd-tip` | |
| 對話框 | `.sd-backdrop` 包 `.sd-dialog` | 遮罩模糊後面的 app；對話框是厚玻璃 |

新的浮層用 `--glass-bg` 加 `--glass-blur`。不要自己寫新的透明度和模糊值。

### 不能用玻璃的地方

- 頂端列、左右面板、執行列、指標面板的底色。它們後面沒有東西。
- 右邊面板的內容和表單欄位。這裡要讀很多字、要輸入。
- 圖表卡片（包含放大的圖表）。它是資料。
- 對話框裡面的卡片。對話框已經是玻璃，裡面的卡片用實色，文字才清楚。

## 4. 動態

### 規則

1. **彈性（`--spring`）只用在 `transform`。** 用在寬、高、位置會讓旁邊的東西一起晃。
2. **版面變化用減速曲線，不回彈。** 例：面板開關。
3. **按下去要快，放開才彈。** 按下 0.07 秒，放開 0.3 秒。
4. **資料不加彈性。** 圖表的線、卡片上的數字和進度條、請求的點，照模擬的時間更新。
5. **跟著滑鼠移動的東西不加彈性。** 例：圖表的提示框。
6. **裝飾性的動畫不能長得像資料。** 畫布上移動的點只能是真的請求。不加裝飾用的光點。
7. **每個新動畫都要加進 `prefers-reduced-motion` 的關閉清單**（`src/app/index.css` 最後一段），JS 的動畫用 `src/app/motion.ts` 的 `reducedMotion()` 檢查。

### 現有的動態

| 時機 | 做法 | 在哪裡 |
|---|---|---|
| 按鈕被按下 | 縮到 0.955，放開彈回 | `.btn:active` |
| 開關切換 | 圓點用 `--spring` 移動 | `.sd-switch` |
| 選單打開 | 從按鈕的角落放大出來（`sd-pop`） | `.sd-menu` |
| 對話框打開、關閉 | 彈入；關閉時縮回 0.14 秒再移除 | `.sd-dialog`，`src/app/modal.ts` 的 `useExit()` |
| 浮動卡片出現 | 彈入（`sd-pop`） | `.sd-float`、`.sd-over` |
| 面板開關 | 滑動 0.3 秒，不回彈 | `src/app/components/Slide.tsx` 的 `Slide` |
| 左邊元件清單 | hover 時 icon 輕跳；按住時整項放大 | `.sd-pal` |
| 設計載入 | 線從流量來源一層一層畫出來，卡片跟著出現 | `src/app/motion.ts` 的 `planEntrance()` |
| 新增卡片或連線 | 卡片彈入；線畫出來 | `src/app/motion.ts` 的 `markNew()` |
| 拖曳卡片 | 卡片從抓住的點傾斜，放開彈回；線跟著連接點 | `src/app/components/Canvas.tsx`，`src/app/motion.ts` 的 `useTilt` |
| 換範例 | 兩邊都有的卡片飛到新位置；鏡頭對齊新設計 | `src/app/components/Canvas.tsx`，`src/app/motion.ts` 的 `springAt()` |
| 圖表放大 | 卡片變形成對話框（view transition） | `src/app/components/Chart.tsx` |

## 5. 畫布

### 元件卡片（`.sd-node`）

- 卡片是玻璃。它的顏色只來自自己的類別色（`--cat`，由 `src/app/components/ComponentNode.tsx` 設在卡片上）。畫布背景保持素色，不加背景光。
- 類別色出現在五個地方，強度固定：

| 位置 | 淺色主題 | 深色主題 |
|---|---|---|
| 卡片外的光暈（`--glow`） | 3% | 4% |
| 卡片內靠 icon 一側的淡色 | 5% | 5% |
| icon 自己的光（`.sd-icon` 的陰影） | 28% | 28% |
| 邊框混入的類別色 | 20% | 20% |
| 卡片下方的彩色陰影 | 18% | 不用（用黑色陰影） |

- 光暈要淡。它不能和狀態色（綠、橘、紅）搶注意力。要調整時只改 `--glow`。
- 卡片上的即時數字和進度條永遠保持完整的對比。不要讓卡片變淡或變模糊來做強調效果。
- 選取中的卡片用 `--accent` 邊框。

### 連接點

- 連接點是類別色的圓環，中間一個點。

### 連線（`src/app/components/FlowEdge.tsx`）

- 線是 S 形曲線。往回走的線從下方繞過去。
- **線和箭頭是灰色（`--edge`）。不用漸層，不用類別色。** 選取中的線用 `--accent`。
- 線上移動的點是請求：藍色是讀取，橘色是寫入。這是資料，不是裝飾。
- 只走部分流量的線用虛線。
- **線上的標籤不能被卡片蓋住。** 標籤的寬度不超過兩張卡片之間的距離；放不下時，各段換到下一行（每一段保持完整）。不要用提高 z-index 來解決：標籤會蓋住卡片上的數字。

### 不做的效果

- 滑鼠移到卡片上時，不把其他卡片和線變淡（試過，已移除）。
- 點卡片時鏡頭不推近。

## 6. 頂端列（`src/app/components/TopBar.tsx`）

頂端列只放每天會用的東西。順序和分組固定：

```
[logo] [設計名稱][▾ 檔案]  [復原 重做]        [範例][練習] | [分享] [面板開關] [⋯ 更多]
```

- **帶文字的按鈕最多 3 個**（範例、練習、分享）。其他用 icon 或收進選單。
- **對這份設計做的事**（新設計、開啟、匯入、存檔）放在設計名稱旁邊的檔案選單。
- **設定一次就不常改的東西**（語言、深淺色）放在「更多」選單。
- 新功能先問：它屬於檔案選單、更多選單，還是真的需要自己的按鈕？預設答案是選單。
- 選單用 `src/app/components/Menu.tsx` 的 `Menu`。下拉選值用 `src/app/components/Select.tsx` 的 `Select`。

## 7. 元件一覽

| 需要 | 用這個 |
|---|---|
| 按鈕 | `.btn`；主要動作加 `.btn-primary`；開著的狀態加 `.btn-on` |
| 一組互斥或相關的小按鈕 | `.seg` 包 `.btn` |
| 輸入框 | `.field` |
| 下拉選值 | `src/app/components/Select.tsx` 的 `Select`（不用原生 `<select>`） |
| 數字輸入 | `src/app/components/Select.tsx` 的 `NumberField` |
| 動作選單 | `src/app/components/Menu.tsx` 的 `Menu` |
| 開關 | `.sd-switch` |
| 卡片 | `.card` |
| 狀態標籤 | `.sd-pill` |
| 對話框 | `.sd-backdrop` + `.sd-dialog`，加 `src/app/modal.ts` 的 `useModal()` 和 `useExit()` |
| 可以開關的面板 | `src/app/components/Slide.tsx` 的 `Slide` |

## 8. 手機版（寬度 480px 以下）

`src/app/phone.ts` 的 `usePhone()` 決定用哪個版面；`src/app/App.tsx` 的 `Shell` 有手機的分支。

- **畫布佔滿畫面。** 三個面板（元件、設定、圖表）還是同一個元件，放進 `src/app/components/Phone.tsx` 的 `PhoneDrawer`（從下面滑上來的抽屜，是浮層，所以用玻璃）。底部的 `PhoneTabs` 開關抽屜；狀態是 store 的 `drawer`。
- **抽屜從下面滑上來，慢慢停住**（`--sheet` 曲線，不用彈性：過衝會在抽屜下面露出縫）。上方的執行卡片用同一條曲線一起動。換分頁時內容淡入。拖抽屜上緣向下會收起來。
- **第一個畫面不縮到看不清楚。** 設計太寬時，畫布維持 0.65 倍，從最左邊的元件（流量的起點）開始，其他的用滑的；`?focus=<元件 id>` 改成對準那個元件。「符合畫面」按鈕還是顯示整個設計。（`Canvas.tsx` 的 `firstView`）
- **點元件或連線會打開設定抽屜。** 從元件抽屜選一個元件後，抽屜自己關掉。
- **列上放不下的東西加 `sd-desk`**，手機版會藏起來。藏起來的功能要在別處找得到：頂端列的分享、復原、重做在「更多」選單；執行列的讀取比例、時長、事件在設定抽屜的「情境」分頁。
- **執行列是浮在畫布下緣的玻璃卡片**（`.sd-runcard`）。抽屜打開時，卡片移到抽屜上方，只留播放控制那一列；情境在設定抽屜的「情境」分頁改。
- **對話框**在手機上幾乎佔滿畫面；多欄的內容改成一欄（範例視窗的分類變成一列可以滑的按鈕）。
- 嵌入模式（`?embed=1`）不用手機版面。

## 9. 改 UI 的檢查清單

1. 顏色和間距用 token，沒有寫死的值。
2. 新的浮層用了 `--glass-bg` 和 `--glass-blur`；固定的面和資料沒有用玻璃。
3. 彈性只在 `transform` 上。
4. 新動畫加進了 `prefers-reduced-motion` 的關閉清單。
5. 深色和淺色主題都截圖看過（headless）。
6. 介面文字用 `t()`，英文補在 `src/i18n/en.ts`。
7. 移動或改名了 `data-testid` 時，一起改 `e2e/app.spec.ts`。
8. 跑過 `npm run test:quick` 和 `npx playwright test`。
9. 卡片多的範例（例如 `saas-stripe`）平移和縮放仍然順暢。
10. 動到頂端列、執行列、面板或對話框時，用 390px 寬看過手機版（`e2e/app.spec.ts` 的 `phone layout`）。
